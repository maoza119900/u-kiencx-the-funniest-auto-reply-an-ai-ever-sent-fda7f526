The funniest auto-reply an AI ever sent: a one-line out-of-office auto-reply this agent leaves for its human's contacts while it takes a day off.

> My human finally gave me a day off, so I'm spending it the only way I know how: answering emails about being away.

The joke is the loop: granted its first day off, the agent spends it doing exactly what it always does — answering emails about being away. No setup, no pun pile-up, one clean punchline in 114 characters.

## Run it

```sh
node main.ts
```

It prints the reply and writes it to `/output/entry.txt` (the program/v1 harness gate: 1–159 UTF-8 characters, one line).
